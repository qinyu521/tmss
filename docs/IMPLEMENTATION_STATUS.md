- 防御召援不再只改变外交关系：有效盟约使双方共同对敌时，盟友 NPC 会优先评估该敌方边境，并在存在可行攻击目标时立即下达反击行军。
- 仍遵守战略地图道路与战争状态，不生成额外兵力、不瞬移、不修改战斗胜负事实；无可达目标时不强行生成无效军令。

## 0.9.3 将领忠诚与倒戈（本 PR）

- 将领运行时忠诚独立于种子值并存入 schema v7；旧存档 v6 → v7 只补默认值。
- 仅当低忠诚、明确跨阵营强关系、真实战争状态、足够兵力与驻地孤立等条件同时成立时，才发出倒戈预警。
- 预警留出整回合；君主可花 12,000 两赏赐将领、军令忠诚 +25。未挽回时，军团、州府与该州府节点控制权转交目标势力。
- 新增确定性预警/倒戈/赏赐/迁移测试。浏览器手工试玩与长战役平衡仍需验收。

## 0.9.2 道路容量与大军寻路（本 PR）

- 道路 `throughput` 标签参与州府图与 72 节点图的 Dijkstra 路线成本；玩家部队、州兵和 NPC 均按实际调动兵力评估道路负荷。
- 小部队仍可选择更短的低容量道路；大军在路线成本允许时会选择更高容量官道。新增行军天数继承既有补给消耗与疲劳规则，不直接额外扣资源。
- 新增路由倍率阈值与双路径回归测试，覆盖区域图、战略地图和中低/争议道路分类。
- 本实现不把 `control_or_interdiction` 解释为动态封锁；真实地形封路、水运专属运输和长期战役平衡仍需后续实现/试玩。

## 0.9.6 战略节点有限后勤（本 PR）

- 仓储/补给设施与港埠/渡口在部队驻扎休整时提供不同额度的额外补给。
- 额外补给从节点 `supplyLevel` 库存扣除并生成可追溯资源事件；节点与州府行政归属一致时每回合恢复 2 点储备，孤立前进据点不会自动补库。
- 新增仓储补给和库存耗尽的回合结算测试；不增加士兵、不修改战斗胜负，也不改动存档 schema。

## 0.9.5 战败影响将领威信（PR #35，本 PR）

- 统兵官亲率军团战败后，运行时军令忠诚基础 -5；战前伤亡达到 20% 再 -3，胜方统兵官不受该项惩罚。
- 忠诚损失生成确定性政治事件，并遵守现有战争迷雾；不改变确定性战斗胜负、回放或种子人物属性。
- 回归测试使用重复结算的同一战斗场景，验证败方将领忠诚下降且有对应事件。

## 0.9.4 NPC 战略地图节点选敌（本 PR）

- NPC 进攻评估使用存档中 72 节点的实际控制权与 Dijkstra 路径，不再只根据州府邻接图挑目标。
- 可争夺目标包括州府主城、关隘、边塞、港埠、渡口、粮仓等节点；具体节点目标通过 `targetMapNodeId` 下达，目标州府行政归属与节点控制权继续分离。
- 节点驻军、城防、驻地军团、道路容量、估算行军日和防御盟约共同影响选敌；无路可达或敌我未交战时不生成进攻令。
- 为缺少节点运行时数据的旧档保留州府寻路回退，并新增防御盟约响应直接指向敌方独立据点的测试。

## 3. 已知限制（不得隐瞒）

1. **单机/个人模式，无应用内登录鉴权或按用户隔离存档**；Compose 默认仅绑定宿主机回环。远程访问必须使用仅允许实例所有者的 Cloudflare Access/Tunnel 或等效认证网关，不能裸露 API。`SINGLE_PLAYER_MODE=0` 目前会拒绝启动。
2. **LLM Provider 已实现（可选）**，无密钥时回退本地模板；`POST /api/games/:id/chronicle/llm` 只读事实层与事件摘要，仅回写文学/推断表达层，尚未用真实外部服务联调。
3. **无音效/音乐**；设置中为占位开关。
4. **美术为原型级**：肖像为程序化矢量风格（偏插画），不是写实；低多边形模型未使用动画/骨骼。
5. **地图边界**采用地形网格最近州府推导，呈细微阶梯状；地形分辨率高画质 180 段，低画质 90 段。
6. **种子坐标重复**：赤河州（HUN）与辽东州（YONG）在原始数据中同为 `(5,2)`。仅在前端做显示偏移（+0.38, +0.42）并将该州所有节点/部队同步偏移；原始 JSON 未改。已在 `DATA_DICTIONARY` 记录。
7. **战斗为战略级**：抵达敌州府后单次结算，无战术战场/逐日战斗；计谋与统兵官影响为战略层模拟。水战仅通过兵种与地形修正体现。
8. **NPC AI 为启发式**：会征兵、征粮、贸易、调兵与部分政治行动，但暂不主动施计；敌方精确数值不会下发。
