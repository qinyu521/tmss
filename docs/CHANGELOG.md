## 0.9.1 · 2026-10-29（NPC 自主外交）

### 新增
- NPC 势力每三回合按关系、战事、领土和资源压力评估一次外交行动。
- 战争疲劳可触发议和，共同敌人与合格邦交可触发防御盟约，低邦交且有预算时可派使团修好。
- NPC 外交行动有实际使团成本，并沿用正式外交结算、盟约期限和事件账本。
- 玩家作为交涉对象时可见相关外交事件；其他 NPC 军事与内政行动仍隐藏。

- PR #25 的种子校验、完整测试、TypeScript、生产构建和 Docker Compose 检查均通过并合并。
