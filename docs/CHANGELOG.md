# 变更记录

## 0.9.0 · 2026-10-29（正式外交行动与防御盟约）

### 新增
- 正式外交命令：派使团修好、宣战、议和、提出防御盟约、废止盟约。
- 邦交分数与条约分开存储；新增有效期八回合的防御盟约和过期历史记录。
- 宣战立即改变战争判定；目标势力的盟友按有效防御盟约参战。
- 外交行动有明确成本、关系门槛、国君权限与每回合一项的限制；议和/结盟采用确定性接受评估。
- 人物/势力事件日志记录外交行动的成本、关系前后值、接受/拒绝结果和条约 ID。
- 存档升级到 schema v6；v5 → v6 迁移为旧存档补齐空条约账本，不自动创建盟约。

### 验证
- 已添加修好、宣战、议和、缔盟、盟约到期、召援、权限和回合命令上限测试；CI 待当前 PR 验收。
- 浏览器外交面板仍需人工目视验收。
