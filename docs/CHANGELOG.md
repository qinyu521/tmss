# 变更记录

## fix/engine-hardening · 2026-10-29（AI 连接诊断与本地模型支持，未发布）

### 新增
- **模型发现**：新增 `POST /api/llm/models`，设置页可「获取模型」拉取 OpenAI 兼容 `/models` 列表并直接选择模型名。
- **地址容错**：`normalizeBaseUrl` 自动补 `https://` / 本机 `http://`、补 `/v1`、去掉误粘贴的 `/chat/completions` 或 `/models` 后缀；保存与测试均使用规范化地址。
- **本地免密钥端点**：本机/局域网 Ollama 等端点允许不填 API Key；新增 Ollama、硅基流动、OpenRouter 预设。
- **连接诊断**：连接测试与模型拉取会返回 HTTP 原因和响应片段，专门识别 Render `no-server`、404 地址失效、401/403 密钥问题、429 限流与 502/503 上游不可用；密钥片段自动脱敏。
- **设置页提示**：新增排查清单，说明服务下线、`/v1`、密钥、模型名与 Ollama 的检查顺序。

### 修复
- **生产静态资源遮蔽**：此前 API 同时挂载 `public/assets` 与 `dist`，`/assets/` 请求先命中 `public/assets`，导致 Vite 构建的哈希 JS/CSS 返回 HTML、页面无法加载；现在存在 `dist` 时只由 `dist` 提供静态资源（其中已包含 public 资源）。
- **模型列表陈旧**：修改 API 地址后清空已发现的模型与探测提示，避免把上一地址的结果误当成新地址。

### 验证
- 全量 10 个测试文件 **132/132** 通过；新增本机免密钥、地址规范化、模型列表、已下线端点诊断测试。
- 使用本地 mock OpenAI 兼容服务完成真实 HTTP 端到端验证：模型列表、连接测试、史官润色均通过（见 `docs/IMPLEMENTATION_STATUS.md`）。
- Playwright 实测设置页：获取模型下拉、连接成功、已下线端点诊断提示均正确，修改地址后旧模型列表即时清空；控制台无意外错误。

## fix/engine-hardening · 2026-10-29（水墨视觉、逐格行军演出与 AI 史官设置，未发布）

### 新增
- **AI 史官设置**：开始页与游戏内「设置 → AI 史官」两处入口；提供 OpenAI / DeepSeek / Moonshot / 通义千问 / 智谱 GLM 预设，可填写地址、模型、密钥、超时、文风与自动润色，并单独「测试连接」。
- **本机配置存储**：迁移 `002_app_settings.sql` 新增 `app_settings` 表；`GET/PUT /api/llm/config`、`POST /api/llm/test` 读写本机配置。密钥仅存本机 SQLite，读取只回传 `hasKey` 与末四位掩码；界面设置优先于 `LLM_*` 环境变量。
- **演义体长文润色**：`llm.ts` 新增史记/演义/评书三种文风提示词，演义体要求 220–360 字，写清人物、对话、计谋定计、伪装、敌方反应与结果；事实层、标题与事件来源保持只读。
- **自动与手动润色**：结束回合后按 `llmAutoPolish` 自动润色本旬条目；史官页可手动「AI 润色本旬」，失败时保留模板并提示原因。
- **行军演出**：回合结算后军队沿上一旬 `tilePath` 前缀逐格插值移动，镜头跟随至目的地；新增「行军日报」，列出起止格、格数、抵达/续行状态与战报摘要。
- **视觉调整**：地图改为更明亮的羊皮纸水墨色调，补充环境光、降低暗角，州府/军团/资源标签更清晰；设置分区标题左对齐。

### 修复
- OpenAI 兼容服务不支持 `response_format: json_object` 时，遇 400/422 自动退回普通 JSON 重试。
- 连接测试对 401/403、404、429 与网络异常给出明确原因，不再只显示笼统失败。
- 修复 `.map-tooltip` CSS 缺少闭合 `}` 导致后续样式被吞的问题。

### 验证
- `npm test`：10 个测试文件 **130/130** 通过；新增 AI 史官本机设置测试覆盖保存、掩码、连接测试、实际润色与清除密钥。
- `npm run typecheck` 三段通过；`npm run build` 通过（CSS 35.21 kB / gzip 8.09 kB，JS 844.82 kB / gzip 239.96 kB）。
- Playwright 实测：点格行军 `(18,39) → (28,39)` 共 10 格，次旬抵达并生成含战报的行军日报；设置页配置、密钥掩码、连接测试提示均正常；控制台无意外错误（无密钥或地址不可达时返回预期错误）。
