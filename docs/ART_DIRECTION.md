# 美术方向 · 天命史书

原则：原创、程序化、低多边形、强识别；不使用任何商业游戏截图、头像、字体、音效、模型或素材。

## 1. 设计 Token（唯一来源）

`packages/shared/src/constants.ts → FACTION_VISUALS`

| 势力 | 主色 | 强调 | 地图填色 | 旗帜字 | 视觉语言 |

界面基调：墨黑/炭褐底、米白正文、铜金强调、暗朱警戒；标题用宋体/衬线，数据用无衬线或等宽。

## 2. 3D 大地图

- 由 24 州府坐标生成地形顶点归属（最近州府）着色，边界由地形网格上的归属变化推导：保证无空洞、无重叠压盖。
- 原始种子中赤河州与辽东州共用 `(5,2)`；前端仅对辽东州做显示偏移 `(+0.38,+0.42)`，并在数据字典记录，原生坐标不改。
- 地形：确定性值噪声 + 山脉折线抬升 + 东/南海岸下沉；顶点着色（沙岸/草场/岩地/雪线）。
- 河流/湖泊/森林/岩石：`data/derived/map_art.json` 的原创架空地理，仅视觉，不改变道路。
- 道路：按 31 条原始边绘制；派生边若存在会以青绿虚线区分（本版无）。
- 州府标记按节点类型生成：主城（城体+四角攒尖顶+旗）、关隘（双塔+门墙）、港口（栈桥+船+桅）、粮仓（圆仓+锥顶）、矿场、牧场、市场、集镇。
- 部队：底盘 + 旗 + 1-3 个兵种剪影；近景显示模型，远距切换兵种图标 sprite；行军中显示虚线路径与目标旗标。
- 标签为 HTML 覆盖层，随镜头投影；低画质隐藏次要资源点标签。
- 信息密度靠图层与右侧详情承载，地图本身保持可读。

## 3. 人物肖像（336 张）

脚本：`scripts/generate-portraits.mjs`，输出 `apps/web/public/assets/portraits/{person_id}.svg`。

- 稳定种子：`person_id + 姓名 + 身份` 的 FNV 哈希 → mulberry32。
- 变化维度：脸型宽高、肤色、发色、发型（含女性发髻）、胡须 6 型、年龄皱纹、眼眉、嘴型、头饰（君主冠/皇子玉冠/文官幞头/将盔/世家软冠/商贾帽/学者巾/平民束带）、服饰（甲胄/圆领官袍/商旅/世家纹样/山野）、势力纹样背景与身份徽记。
- 九类身份：ruler / royal / official / general / house / warlord / merchant / scholar / common，轮廓与服饰明显不同。
- 不写名字进图，避免字体差异；UI 叠层显示姓名。
- 图片为本地 SVG，不热链外部资源。

生成统计：ruler 3、royal 24、official 123、general 71、house 54、warlord 36、scholar 16、merchant 3、common 6，共 336。

## 4. 兵种视觉

图标：`scripts/generate-unit-icons.mjs`，输出 `apps/web/public/assets/units/{unit_id}.svg`，22 张，按兵种类别给出骑兵（重甲/弓骑/轻骑/禁卫）、重步、突击、禁卫、长矛、强弩、水军、山地轻装等剪影，并用势力色、兵种徽记变体与数量点区分同类别。

3D：`apps/web/src/three/mapScene.ts → buildUnitFigure` 按 `unitId` 组合马匹、骑手、甲胄、盾、弓/弩/长兵/斧钺、旗帜；重骑加马甲，水军有船体/桅/帆，山地兵有弓与短装。远景使用 `/assets/units/{unit_id}.svg` 作为 Sprite，近景为低多边形模型。

## 5. 可访问性与信息表达

- 关键告警不仅靠颜色：同时使用文字标签（短缺、拒命、危机、抵制）、虚线/边框、图标与说明。
- 文字对比度：米白正文在深色面板上；铜金用于强调但不承载唯一信息。
- 低分辨率：右栏可折叠；导航保持 52px 宽；底部战报可滚动。
- 设置中提供低画质与标签开关，减少低端设备压力。

## 6. 禁止事项

- 不复制《三国志》等商业游戏的 UI 布局、人物头像、地图、字体、音效与模型。
- 不使用现代网络梗破坏语感；黑色幽默服务于历史情境。
- 不使用外部图片热链；所有资产随仓库分发。
